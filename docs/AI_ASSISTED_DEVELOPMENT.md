# 역할과 AI 활용

Tanya는 AI 도구를 활용한 개인 프로젝트입니다. 이 문서는 사람의 판단, AI의 구현 기여, 실제로 확인한 범위를 구분합니다.

## 담당한 판단과 작업

제품 방향과 기능 우선순위, 완료 기준, 인프라 구성과 외부 서비스 설정을 담당했습니다. 계정·비밀값은 직접 관리하고, 실제 기기의 화면·음성·사용 흐름을 확인해 결함과 다음 우선순위를 전달했습니다.

구체적으로 승인 대상을 구별하기 어려운 화면, 좁은 화면의 마이크 버튼, 음성 미출력·오인식, 선택 후 스크롤 문제를 실사용에서 발견하여 수정 요구로 연결했습니다. 음성 변경은 직접 청취한 뒤 진행 여부를 판단했습니다.

## Claude와 Codex의 기여

Claude와 Codex를 요구사항 구체화, 설계, production code 구현, 테스트 작성, 코드 리뷰, 문서화와 통합 작업에 활용했습니다. 작성된 코드를 모두 직접 타이핑했다고 주장하지 않습니다.

변경은 Task 단위로 범위와 완료 조건을 정하고, 실제 diff와 테스트 결과를 확인하는 흐름으로 관리했습니다. 구현과 리뷰를 분리한 검토 패스도 활용했습니다. 이 공개 스냅샷에는 전체 내부 작업 기록 대신 [대표 문제 해결 사례](ENGINEERING_CASES.md)와 해당 소스·테스트를 남겼습니다.

## 완료 기준으로 관리한 원칙

- 제안에 대한 호응을 외부 변경 승인으로 간주하지 않기.
- 실제 변경 필드와 실행 주체를 승인 전에 보여주기.
- 공개 튜토리얼에서 일회성 승인을 저장된 초안에 결속하기.
- 실제 provider 결과 없이 성공을 표시하지 않기.
- 공개 튜토리얼의 불확실한 실행 결과를 자동 재실행하지 않기.

이 원칙을 모든 경로에 동일하게 완성했다고 표현하지 않습니다. 예를 들어 데스크톱 성공 영수증 캐시와 공개 튜토리얼의 영속적인 실행 상태 복구는 구현 수준이 다릅니다.

## 검증 범위

자동 테스트·빌드, Google 생성·조회·삭제, 재시작·브라우저 복구의 개발 검증을 수행했습니다. 모든 변경마다 Windows·모바일·Google 종단 검증을 전부 완료했다는 뜻은 아닙니다.

실제 휴대폰 STT 품질, NVDA, 캘린더 앱 저장과 네이티브 창·음성 판정 등은 남은 항목을 별도로 명시합니다. 스냅샷의 최신 자동 검증 결과는 [README](../README.md)와 [SETUP](SETUP.md)을 기준으로 확인합니다. 제3자 모델의 사용 조건도 검증 완료 기능과 분리합니다.
