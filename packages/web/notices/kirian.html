키리안 공개 데모 · 고지 및 이용 조건

이 페이지는 데모에 포함된 제3자 구성 요소와 방문자에게 적용되는 조건을 안내합니다. 출처 표기는 해당 자료의 이용 허락이나 재배포 허락을 뜻하지 않습니다.

Live2D Cubism SDK

캐릭터 표시에는 Live2D Inc.의 Cubism Core와 Cubism Web Framework가 사용됩니다. Copyright (c) Live2D Inc. All rights reserved.

  • Cubism Core는 Live2D Proprietary Software License Agreement, Cubism Web Framework는 Live2D Open Software License Agreement를 따릅니다. 보존된 고지: Core, Framework.
  • 방문자 조건: 이 페이지가 브라우저에 전달하는 Cubism Core·Framework 파일은 키리안 데모를 실행하기 위한 것입니다. 이를 추출·복제·수정·재배포하거나 다른 라이선스로 배포할 수 없으며, 위 Live2D 계약이 정한 것과 동등한 보호 조건이 방문자에게 적용됩니다.
  • 데모는 고정된 캐릭터 하나만 표시하며 방문자가 모델을 추가하거나 올리는 기능은 없습니다.

키리안 캐릭터

표시되는 캐릭터(Kirian UpperBody Rig v001)와 그 원화·모델 파일은 운영자의 자산이며 출처 기록이 있습니다. 브라우저에 전달된 모델 파일을 저장·재배포·2차 이용할 수 없습니다. 이 기록은 캐릭터의 공개 재배포나 홍보 이용 권리를 주장하지 않습니다.

음성

음성 답변은 Qwen 팀의 Qwen3-TTS(Apache-2.0) 기본 제공 한국어 음성 Sohee로 서버에서 합성됩니다. 특정인의 목소리를 녹음·복제한 것이 아닙니다.

대화 모델

답변은 서버의 Ollama가 실행하는 Gemma 4 파생 모델이 생성합니다. Google의 Gemma 4는 Apache-2.0으로 공개되었고 별도의 금지 사용 정책이 있습니다. 사용 중인 파생 모델(HauhauCS)의 모델 카드는 gemma 라이선스를 표기하고 있어, 파생 모델은 Google의 Gemma 이용 약관과 금지 사용 정책이 적용되는 것으로 취급합니다. 모델 가중치는 이 페이지에 포함되지 않습니다.
