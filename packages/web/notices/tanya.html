타냐 공개 데모 · 고지 및 이용 조건

이 페이지는 데모에 포함된 제3자 구성 요소와 방문자에게 적용되는 조건을 안내합니다. 출처 표기는 해당 자료의 이용 허락이나 재배포 허락을 뜻하지 않습니다.

Live2D Cubism SDK

캐릭터 표시에는 Live2D Inc.의 Cubism Core와 Cubism Web Framework가 사용됩니다. Copyright (c) Live2D Inc. All rights reserved.

  • Cubism Core는 Live2D Proprietary Software License Agreement, Cubism Web Framework는 Live2D Open Software License Agreement를 따릅니다. 보존된 고지: Core, Framework.
  • 방문자 조건: 이 페이지가 브라우저에 전달하는 Cubism Core·Framework 파일은 타냐 데모를 실행하기 위한 것입니다. 이를 추출·복제·수정·재배포하거나 다른 라이선스로 배포할 수 없으며, 위 Live2D 계약이 정한 것과 동등한 보호 조건이 방문자에게 적용됩니다.
  • 데모는 고정된 캐릭터 하나만 표시하며 방문자가 모델을 추가하거나 올리는 기능은 없습니다.

캐릭터

표시되는 캐릭터는 Live2D Inc.가 배포하는 샘플 모델 Mao (니지이로 마오, 프로 버전)입니다. © Live2D Inc. 이 자료는 Live2D Free Material License Agreement에 따라 이 데모에 사용되며, 브라우저에 전달된 모델 파일을 저장·재배포·2차 이용할 수 없습니다. 텍스처는 웹 전송을 위해 2048px로 축소되었고, 표정 프리셋 파일은 데모 운영자가 작성한 것입니다.

음성

음성 답변은 Qwen 팀의 Qwen3-TTS(Apache-2.0) 기본 제공 한국어 음성 Sohee로 서버에서 합성됩니다. 특정인의 목소리를 녹음·복제한 것이 아닙니다.

대화 모델

답변은 서버의 Ollama가 실행하는 Gemma 4 E4B(Google의 공식 google/gemma-4-e4b-it 가중치를 Unsloth가 GGUF Q4_K_M으로 변환한 파일)가 생성합니다. 공식 모델 카드는 Apache-2.0을 표기하며, Google의 Gemma 금지 사용 정책과 의도된 사용 안내가 함께 적용됩니다. 모델 가중치는 이 페이지에 포함되지 않으며, 데모는 대화 텍스트와 일정 초안 도구 호출에만 모델을 사용합니다.

데모 이용

  • 대화는 세션이 끝나면 지워지며 저장되지 않습니다. 개인정보를 입력하지 마세요.
  • 일정 초안은 방문자가 화면에서 승인하기 전에는 아무것도 실행하지 않습니다. 승인한 일정은 운영자의 공개 데모 캘린더(누구나 볼 수 있음)에 [데모] 제목으로 실제로 만들어졌다가 약 60분 뒤 자동 삭제됩니다. 방문자 개인의 Google 계정에는 접근하지 않습니다.
  • 세션당 대화 30회, 메시지 500자, 10분 방치 시 종료, 같은 네트워크에서 동시 2세션까지 허용됩니다. 서버 자원 보호를 위해 요청이 몰리면 잠시 거절될 수 있습니다.
  • 음성은 서버에서 문장 단위로 합성되어 브라우저에서 재생되며, 방문자의 마이크는 사용하지 않습니다.
  • 데모의 화면·음성·캐릭터를 녹화·재배포·홍보에 사용하려면 운영자의 허락이 필요합니다.
